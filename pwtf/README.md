# PWTF · 密码变奏

纯静态页面，直接由 GitHub Pages 提供，不依赖构建步骤、外部字体或第三方脚本。

## 本地预览

在仓库根目录运行：

```powershell
python -m http.server 4173 --bind 127.0.0.1
```

然后访问 `http://127.0.0.1:4173/pwtf/`。页面使用 ES modules，需要通过 HTTP 打开。

## 文件

- `index.html`：语义结构、表单和内联 SVG 图标。
- `styles.css`：鼠尾草绿主题和响应式布局。
- `app.js`：验证、复制、显隐、当前页面中的平台历史。
- `transform.mjs`：与旧页面兼容的转换规则和口令检查。

平台名称保留原始拼写、大小写和空格，不做会改变旧密码结果的自动规范化。少于两个字符时显示错误，避免旧规则产生无效结果。

输入、结果和最近平台名称仅在内存中处理；不发网络请求，不写入本地或会话存储。历史记录只保留最近六个平台名称，不保留生成结果或口令；页面离开时清空口令和结果。

当前规则和旧版口令判断保持兼容；前端口令判断并非服务端认证，也不能让旧转换规则成为现代密码派生算法。界面重构未改变用户原有的平台密码。

## 兼容性回归

```powershell
node --test pwtf/transform.test.mjs
```

测试使用从旧页面取得的固定结果，覆盖大小写、中文、长名称及无效输入。
